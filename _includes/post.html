{%- comment -%} Blog card. The wrapper is a container, so the card reacts to the width of its own column rather than the viewport: once the column is wide enough for a side-by-side layout it takes one, whichever grid it happens to sit in. This is what the dead .card-lg rule in _blog.scss was reaching for. The image and the title carry per-post view-transition-names so the card morphs into the post it links to (_layouts/post.html names the same two things). `named` gates them: this include also renders the "Similar Stories" list at the bottom of a post page, which contains the post you are already reading, and a view-transition-name repeated in one document does not degrade -- it aborts the whole transition. {%- endcomment -%} {%- assign named = true -%} {%- if post.url == page.url -%}{%- assign named = false -%}{%- endif -%}
