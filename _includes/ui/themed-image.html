{%- comment -%} Light/dark image pair. Renders a single unless src_dark is set, in which case both images are stacked in one wrapper -- the light one in flow, the dark one absolutely positioned over it at the same box -- and revealed by opacity (see _tailwind/main.css's "Light/dark image pairs" block and assets/js/themed-image-pairs.js). The dark file's pixel dimensions are asserted to match src's at build time by _plugins/themed_image_pairs.rb, so the stacking here can assume the two boxes already agree. Params: src - required. Light (default) image, site-absolute or relative_url-able. src_dark - optional. Dark variant of the same image. alt - alt text for src. The dark layer is decorative (alt=""). transition - view-transition-name, applied to the wrapper (or the itself when there is no src_dark) rather than to src alone, since the wrapper is what a caller floats/margins and what an in-page scheme swap needs to snapshot as one box. class - classes for the outer element (float, margin, max-width). img_class - classes shared by both layers (rounding, object-fit). {%- endcomment -%} {%- if include.src_dark and include.src_dark != "" -%} {%- else -%} {%- endif -%}
